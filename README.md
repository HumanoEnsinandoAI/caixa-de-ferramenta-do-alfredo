# Humano e sua caixa de ferramentas

O marketplace de plugins do [humanoensinando.ai](https://humanoensinando.ai), do Alfredo Gazperi. Você instala uma vez e passa a receber tudo o que ele publicar aqui no seu agente de IA (Claude Code).

## Instalar

```
claude plugin marketplace add HumanoEnsinandoAI/humano-e-sua-caixa-de-ferramentas
claude plugin install pergunte-ao-alfredo@humano-e-sua-caixa-de-ferramentas
```

Depois, no Claude Code, rode `/mcp`, escolha **humanoensinando** e entre com a sua conta da plataforma. Para receber as novidades: `claude plugin marketplace update humano-e-sua-caixa-de-ferramentas`.

## O que tem aqui

| Plugin | O que faz |
|---|---|
| `pergunte-ao-alfredo` | Quando você tem uma dúvida sobre trabalhar com IA, o seu agente busca nos vídeos do Alfredo o trecho certo e dá o link, já no minuto. Exige conta e assinatura ativa na plataforma. |

Mais plugins entram aqui com o tempo.

## O que NÃO tem aqui

Os vídeos e a minutagem ficam na plataforma, atrás do login e da assinatura. Este repositório só tem as instruções (as skills) e o endereço do MCP.
